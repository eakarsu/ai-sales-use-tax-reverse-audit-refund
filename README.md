# Sales & Use Tax Reverse-Audit Refund

Find overpaid sales and use tax and prepare defensible vendor-credit or jurisdiction-refund claims.

**Primary buyer:** Multi-state businesses and tax departments. **Evidence:** purchase transactions, invoices, tax codes, product use, exemptions, jurisdiction rates, accruals, vendor credits, refund statutes, claims, and refunds.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Transaction ingestion
- Tax code normalization
- Product service classification
- Use location determination
- Jurisdiction rate validation
- Exemption mapping
- Manufacturing exemption
- Resale exemption
- Duplicate accrual detection
- Vendor tax error detection
- Refund statute monitoring
- Sample projection control
- Claim evidence package
- Refund cash tracking
- Entity jurisdiction analytics

Run `./start.sh`, then open <http://127.0.0.1:4683>. API: `5683`.
